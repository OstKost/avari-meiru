Avari Mieru объединяет профиль подключения, управление туннелем и состояние VPN в простом интерфейсе. Проект находится на стадии MVP: перед установкой ознакомьтесь с ограничениями платформ и примечаниями к релизу.

### Возможности

- Ручная настройка и импорт JSON-профиля.
- Управление подключением, состоянием и очищенными логами.
- Системный трей на desktop и Android VPN Service.
- Закреплённая версия ядра mbox с поддержкой Mieru.

### Платформы

| Платформа | Состояние |
| --- | --- |
| macOS Apple Silicon | MVP, debug-сборка |
| Linux x86_64 | MVP для Ubuntu 24.04, Debian 13 и Arch; нативная desktop/polkit приёмка пройдена ([отчёт](packaging/linux/ACCEPTANCE.md)) |
| Android 8+ | MVP, debug APK для arm64-v8a и x86_64 |
| Windows и iOS | Отложены |

Для подключения нужен собственный работающий сервер Mieru и действующие учётные данные. Примеры профилей содержат фиктивные данные.

## Интерфейсы

Скриншоты клиента пока не подготовлены. В desktop-приложении доступны профиль, подключение, статус и логи; в Android — экран профиля и управление VPN. Мы добавим реальные снимки после подготовки демонстрационных данных.

Сервером можно управлять из терминала через `mieru-admin tui`. Схематичный пример главного экрана (данные вымышлены):

```text
 Mieru Admin TUI  |  Управление сервером Mieru (mita)

 • ОС: Ubuntu (x86_64, 24.04)
 • Пакет mita: Установлен (3.38.0)
 • Systemd служба: active (running)
 • Mita proxy: RUNNING
 • Основной TCP порт: 28443
 • Пользователей в системе: 1

 Меню управления
 ↑/↓: выбор пункта  •  Enter: открыть  •  q/Esc: выход
```

Мастер настройки запрашивает адрес сервера, TCP-порт, имя пользователя и пароль, затем показывает изменения перед применением.

## Установка сервера

На VPS с Ubuntu 24.04 или Debian 13, x86_64 и systemd можно собрать менеджер из исходников (нужен Go и доступ к зависимостям):

```sh
git clone https://github.com/OstKost/avari-meiru.git
cd avari-meiru/server
CGO_ENABLED=0 go build -trimpath -o mieru-admin ./cmd/mieru-admin
sudo ./mieru-admin setup
```

`setup` устанавливает менеджер и его службу и открывает TUI. Установите `mita` по [ручной инструкции](docs/VPS_SETUP.md), затем настройте сервер в мастере; откройте выбранный TCP-порт в сетевом firewall VPS. Затем используйте адрес, порт и учётные данные в клиенте. Для повторного запуска интерфейса: `sudo mieru-admin tui`. API менеджера слушает только localhost. Подробности и альтернативная ручная установка: [server/README.md](server/README.md) и [docs/VPS_SETUP.md](docs/VPS_SETUP.md).

## Состояние проекта

Desktop-клиент на Tauri v2, Rust и лёгком TypeScript-интерфейсе. VPN-туннель обслуживает закреплённое ядро [enfein/mbox](https://github.com/enfein/mbox); приложение управляет профилем, процессом ядра и системным треем.

Готовы macOS debug-приложение для Apple Silicon, Android debug APK и Linux x86_64 пакеты для Ubuntu 24.04, Debian 13 и Arch. Android проверен на эмуляторе с внешним сервером; Linux GUI/helper успешно прошли как предварительные тесты в Xvfb, так и полную нативную приёмку в реальном сеансе Ubuntu 24.04 X11/Xfce с polkit-gnome, маршрутизацией через VPS `31.58.213.192:28443` и проверкой трея ([packaging/linux/ACCEPTANCE.md](packaging/linux/ACCEPTANCE.md)). Для серверного управления доступен менеджер `mieru-admin` (TUI и localhost REST API), прошедший нативную проверку автозапуска и управления службой под реальным systemd ([server/SMOKE.md](server/SMOKE.md)). Установка и удаление пакетов проверены на трёх целевых дистрибутивах. Intel macOS GUI, физический Android и Windows не проверены; Windows отложен.

## Android и Linux: текущий результат

Android APK: `android/app/build/outputs/apk/debug/app-debug.apk` (arm64-v8a и x86_64). Команды сборки и установки: [android/README.md](android/README.md). На AVD Avari_API_36 подтверждены HTTP/HTTPS с IP VPS `31.58.213.192`, DNS, сохранение туннеля при закрытии Activity, отключение с восстановлением исходного IP и повторное подключение. Доказательства: [android/SMOKE.md](android/SMOKE.md). Это debug MVP; Android 8/API26 и физические устройства отдельно не проверены.

Linux-ядро: `core/dist/sing-box-x86_64-unknown-linux-gnu`, сборка `./core/build-linux.sh`. В изолированном Ubuntu 24.04 amd64 Docker проверены loopback proxy, системный TUN, DNS через Mieru, HTTPS и IP VPS. После SIGTERM TUN исчез, правила и маршруты восстановились. Это проверка ядра, а не Linux GUI/helper. Доказательства и ограничения: [core/LINUX_SMOKE.md](core/LINUX_SMOKE.md). Целевые GUI-платформы: Ubuntu 24.04, Debian 13 и Arch Linux x86_64.

Linux-пакеты находятся в `packaging/linux/dist/`; инструкции сборки: [packaging/linux/README.md](packaging/linux/README.md). Нативная приёмка выполнена в реальной виртуальной машине Ubuntu 24.04 amd64 (X11/Xfce + logind + polkit-gnome) с живым трафиком через VPS `31.58.213.192:28443`: отмена диалога авторизации (код 126), подтверждение пароля и подъём `tun0`, HTTPS HTTP/2 200 OK к `example.com`, внешний IP strictly равен `31.58.213.192`, DNS hijack через ядро, сворачивание/показ окна через Ayatana D-Bus меню трея, отключение, повторное подключение (reconnect) и аварийный демонтаж при SIGTERM GUI без утечек процессов. Полный протокол приёмки: [packaging/linux/ACCEPTANCE.md](packaging/linux/ACCEPTANCE.md). Предварительные контейнерные проверки: [docs/LINUX_SMOKE.md](docs/LINUX_SMOKE.md).

Установка Ubuntu/Debian из каталога пакетов: `sudo apt install ./mieru_0.1.1_amd64_ubuntu.deb` либо `sudo apt install ./mieru_0.1.1_amd64_debian.deb`. Для Arch: `sudo pacman -U ./mieru-0.1.1-1-x86_64.pkg.tar.zst`. Затем запустить `mieru` обычным пользователем или через меню приложений; права администратора запрашивает только VPN helper.

Сетевые результаты получены 11 ноября 2026 года до отключения временного VPS в 23:25 МСК; дальнейшая доступность тестового сервера не предполагается. Реальные credentials в документацию и исходники не включены.

## Запуск готового приложения

Из корня проекта:

```sh
open desktop/src-tauri/target/debug/bundle/macos/Mieru.app
```

В приложении можно вручную заполнить профиль или импортировать [JSON-профиль](configs/examples/desktop.json). Данные примера фиктивные: подключаться с ними нельзя. Для реального VPN нужен действующий сервер Mieru (mita), адрес, порт, транспорт и учётные данные; traffic pattern необязателен.

При подключении macOS запрашивает права администратора для сетевого процесса. Сам интерфейс работает от обычного пользователя. Пароль профиля хранится локально в `~/Library/Application Support/Mieru/profile.json` с правами `0600`, без шифрования; это отличается от пароля администратора macOS. Backend не возвращает пароль интерфейсу. Для изменения профиля после перезапуска пароль подключения нужно ввести заново; для подключения сохранённого профиля повторный ввод не требуется.

Закрытие окна скрывает приложение в трее. Меню трея позволяет показать окно, подключиться, отключиться и полностью выйти. При выходе приложение останавливает принадлежащее ему ядро.

Статус «Подключено» означает локальную готовность TUN, а не подтверждение доступности сервера или смены внешнего IP.

## Сборка из исходников

Требуются macOS, Rust/Cargo, Xcode Command Line Tools, Go версии не ниже указанной в [core/README.md](core/README.md), Node.js и pnpm. При первой сборке нужен доступ к зависимостям в сети.

Из корня проекта собрать ядро и установить зависимости интерфейса:

```sh
./core/build-desktop.sh
pnpm --dir desktop/ui install --frozen-lockfile
```

Затем из `desktop/` собрать приложение:

```sh
cd desktop
ui/node_modules/.bin/tauri build --debug --bundles app
```

Результат: `desktop/src-tauri/target/debug/bundle/macos/Mieru.app`. Внутри находятся GUI, sidecar, сведения о ревизии и лицензии ядра. Это debug `.app`; подписанный и нотарифицированный установщик не готовился.

Для нативной разработки из `desktop/`:

```sh
ui/node_modules/.bin/tauri dev
```

Веб-превью без нативного backend: `pnpm --dir desktop/ui dev` из корня. В браузере VPN недоступен, что явно обозначено в интерфейсе.

## Проверки и ограничения

Первый macOS MVP проверен с реальным сервером `31.58.213.192:28443/TCP` (mita v3.38.0). После подтверждения прав приложение подняло `utun8`; обычный HTTPS-запрос без прокси вернул IP VPS, загрузка страницы дала HTTP `200`. После нажатия «Отключить» ядро и supervisor завершились, `utun8` исчез, исходное подключение AWG через `utun7` продолжило работу. Приложение затем штатно завершено; процессов Mieru не осталось.

Результаты и точные ограничения: [docs/MACOS_SMOKE.md](docs/MACOS_SMOKE.md). Инструкция сервера: [docs/VPS_SETUP.md](docs/VPS_SETUP.md). После интеграционных исправлений прошли 18 backend-тестов и сборка debug `.app`.

Рабочий временный профиль оставлен в приватном хранилище приложения — до теста пользовательского профиля не было. После выключения временного VPS этот профиль перестанет подключаться. Credentials отсутствуют в документации и исходниках.

Дополнительно проверены подключение и выход из трея при активном TUN, работа со скрытым окном и возврат через «Показать окно». При аварийном SIGKILL только GUI supervisor и ядро самостоятельно завершились за ~0,41 с, маршруты вернулись к AWG; после перезапуска GUI корректно показал disconnected и очистил stale-сессию. Приложение оставлено открытым без подключения для следующего теста.

В одном повторном проходе был сетевой таймаут. Его устойчивая причина не установлена; последующие loopback-пробы и полный повторный TUN прошли без изменения кода. Это ограничение зафиксировано в [диагностике](docs/RECONNECT_DIAGNOSTIC.md); длительная стабильность не подтверждена.

Следующий этап macOS — подключение без AWG; пока AWG не отключался. Для macOS также не проверены DNS/IPv6-утечки, скорость, смена сетей и Intel GUI. Результаты Android и Linux приведены отдельно выше. Полный аудит и нагрузочное тестирование не проводились.
